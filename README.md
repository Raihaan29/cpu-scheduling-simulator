# CPU Scheduling Simulator

## Overview
The **CPU Scheduling Simulator** is a modern interactive web application built to demonstrate how operating systems schedule processes using different CPU scheduling algorithms.  
The platform provides clear visualization through dynamic Gantt charts and calculates performance metrics to support academic learning and system analysis.

---

## Key Features
- Multiple CPU scheduling algorithm implementations
- Interactive process input system
- Real-time Gantt chart visualization
- Performance metrics dashboard
- Responsive and modern UI design
- Step-by-step simulation support for educational use

---

## Implemented Algorithms
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Round Robin (RR)
- Priority Scheduling
